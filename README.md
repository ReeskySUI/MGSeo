# MGSeo

一个 Typecho 插件搞定三件 SEO 刚需：

1. **动态站点地图**：`/sitemap.xml` 实时生成，包含首页、文章、独立页面、分类、标签，发布新内容自动更新；
2. **动态 robots.txt**：`/robots.txt` 实时生成，规则可自定义，Sitemap 行自动声明；
3. **蜘蛛日志**：自动识别 Google、Bing、Baidu、Sogou、Yandex、DuckDuckGo、字节、360、Apple、神马爬虫，记录其抓取路径与时间，后台「控制台 → 蜘蛛日志」查看。

## 设计原则

- 不写静态文件，无需根目录可写权限，适合 Docker 部署（根目录不持久化）；
- 不修改 Typecho 源码，不依赖任何主题，可单独部署；
- 无外部依赖，无前端框架；日志仅保留最近 30 天，面板展示最近 100 条，自动保持轻量；
- 兼容 Typecho 支持的全部数据库：MySQL、PostgreSQL、SQLite，建表与查询均按数据库方言处理。

## 安装

1. 将 `MGSeo` 文件夹上传到 `usr/plugins/` 目录；
2. 若此前启用了第三方 Sitemap 插件或 MGRobots 插件，请先停用它们（避免路由重复）；
3. 在后台「插件管理」中启用 **MGSeo**；
4. 访问以下地址验证：
   - `https://你的域名/sitemap.xml`
   - `https://你的域名/robots.txt`
5. 如需自定义 robots 规则，进入插件「设置」编辑；设置页顶部也列出了完整的检查地址。

## robots.txt 自定义示例

在插件设置中逐行填写标准规则，例如：

```
User-agent: *
Disallow: /admin/
Disallow: /feed/
```

Sitemap 行会自动追加，无需手动填写。

## 日志说明

- 仅在识别到已知搜索引擎爬虫时写入，不记录普通访客，无性能负担；
- 后台面板可查看各爬虫抓取次数、最近抓取时间（按站点设置的时区显示）和最近 100 条明细，也可一键清空；
- 日志时间按 UTC 存储，面板显示时自动转换为站点时区；
- 禁用插件**保留日志表**，重新启用时数据不丢失；站点地图与 robots 为动态路由，禁用后无残留文件。

## 使用 CDN 缓存时的注意

若站点使用了 Cloudflare 页面缓存（Cache Rule），已被边缘缓存的正文页面不会再到达源站，因此这些抓取不会被记录；保持 `/sitemap.xml`、`/robots.txt` 不被缓存，蜘蛛对这两个地址的抓取仍会正常记录。

## 边界

- 插件不含图片上传、关键词推送等功能，只做搜索引擎发现与抓取分析这三件刚需；
- Sitemap 不附带 XSL 美化样式，浏览器打开显示原始 XML（搜索引擎不受影响）；
- 向 GSC/Bing 提交站点地图，地址为 `https://你的域名/sitemap.xml`（或带尾斜杠的形式），只需提交一次。
